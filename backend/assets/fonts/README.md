# Шрифты для 3D-типографики (`lib/typography3d.ts`)

Надписи `FS` / `SCATTER` / `BIG WIN` рисует librsvg внутри sharp. Семейство он
резолвит через **fontconfig** — то есть по системным шрифтам контейнера.

## Проблема

Railway собирает бэкенд через **RAILPACK**, а не Docker (`railway.json`), и
`apt-get install fonts-*` вписать некуда. На базовом Node-образе системных
шрифтов может не быть вовсе. librsvg в этом случае **не падает** — он молча
рисует пустоту или подставляет что попало. Дизайнер увидит это уже на готовом
баннере.

Локально проблемы нет: на Windows находится Arial Black, на macOS — свои.
Поэтому расхождение «у меня работает / на проде пусто» здесь очень вероятно.

## Что нужно положить

Один файл в эту папку:

```
backend/assets/fonts/DesignPowerDisplay.ttf
```

Требования к шрифту:

- формат **TTF или OTF**;
- начертание **Black / Heavy / ExtraBold** — эталоны используют очень жирный
  гротеск, тонкий шрифт не даст объёма при фаске;
- латиница + цифры обязательны; кириллица нужна, только если токены будут
  на русском;
- **лицензия, разрешающая встраивание в серверный рендер** (SIL OFL, Apache 2.0
  или коммерческая на веб/приложение). Подойдут, например, Montserrat Black,
  Archivo Black, Anton — все под SIL OFL.

Имя файла может быть любым: fontconfig читает семейство из метаданных самого
шрифта, а не из имени. Но семейство внутри файла должно совпадать с тем, что
стоит первым в `TYPO_FONT_STACK` (по умолчанию `Design Power Display`), либо
переменную нужно поправить под реальное имя семейства.

## Как это подхватывается

`config/fonts.conf` объявляет эту папку каталогом шрифтов, а переменная
окружения `FONTCONFIG_PATH` указывает fontconfig на неё:

```
FONTCONFIG_PATH=/app/backend/config
```

На Railway переменная задаётся в настройках сервиса (Variables). Локально она
не нужна — системные шрифты и так находятся.

## Как проверить

```
npm run check:fonts
```

Скрипт печатает, какие семейства реально резолвятся, и отдельно проверяет
стек из `TYPO_FONT_STACK`. Ненулевой код возврата = шрифт не найден.

Ту же проверку делает `assertFontAvailable()` — её стоит звать на старте
воркера, чтобы деплой без шрифта был виден сразу, а не на первом баннере.
